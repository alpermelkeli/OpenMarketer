Boundaries we keep
  • Graphs are thin wiring; domain logic lives in plain Python modules.
  • Nodes call our model router, never a provider directly.
  • Graph nodes cannot reach connectors except through policy-gated tools.
  • Long waits stay in Temporal; graphs only pause for short chat interrupts.
  • Versions are pinned behind a small adapter so graphs can be replaced.
