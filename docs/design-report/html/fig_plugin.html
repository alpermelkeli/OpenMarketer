Plugin contractPlugins are separate Python packages discovered through Python entry points (groups marketer.connectors, marketer.extractors, and so on). Each plugin declares the OAuth scopes it needs and a risk class for every action. A plugin cannot bypass the policy engine, because the registry exposes it to the agent only through the guarded tool surface. Core inclusion requires a sandbox-account test suite and recorded API fixtures.
